## Status Determination Algorithm

```
START: For each calendar day
?
?? Is date FUTURE? (after today)
?  YES ? Status = FUTURE (Gray #444444)
?  NO  ? Continue
?
?? Get PlanDay for this weekday
?  NO PlanDay OR
?  NOT IsTrainingDay?
?  YES ? Status = RESTDAY (Blue #0066FF)
?  NO  ? Continue
?
?? It's a TRAINING DAY
?  Get DailyProgress for date
?
?? Is ALL exercises completed?
?  YES ? Status = COMPLETEDTRAINING (Green #00AA00)
?  NO  ? Status = MISSEDTRAINING (Red #CC0000)
?
?? Return Status

RESULT:
?
?? ?? Green (#00AA00)   ? All done!
?? ?? Red (#CC0000)     ? Incomplete
?? ?? Blue (#0066FF)    ? Rest day
?? ? Gray (#444444)    ? Future
```

## Event Flow

```
User Interaction Timeline:

T1: User opens Workout tab
    ?? ActiveWorkoutPage.OnAppearing()
       ?? Load today's PlanDay exercises

T2: User marks exercise ?
    ?? Button.Clicked ? OnExerciseCompletionToggled()
       ?? CalendarService.MarkExerciseCompletedAsync()
          ?? Create ExerciseCompletion record
          ?? Update DailyProgress summary
             ?? Save to database

T3: User opens Calendar tab
    ?? CalendarPage.OnAppearing()
       ?? CalendarService.GetMonthCalendarAsync()
          ?? For each day:
          ?  ?? GetPlanDay(weekday)
          ?  ?? GetDailyProgress(date)
          ?  ?? DetermineStatus()
          ?? Populate calendar grid
             ?? Set cell color
             ?? Show completion ratio
             ?? Show status icon

T4: User navigates months
    ?? OnPreviousMonthClicked / OnNextMonthClicked
       ?? Update _currentDate
       ?? LoadCalendarAsync() ? Same as T3
```

## Error Handling Flow

```
Any Operation
     ?
Try
 ?? Await CalendarService method
 ?   ?? Await DatabaseService method
 ?   ?   ?? SQLite query
 ?   ?? Status calculation
 ?? Success ? Update UI
     ?
Catch ArgumentNullException
 ?? Show: "Service not initialized"
     ?
Catch InvalidOperationException
 ?? Show: "Database operation failed"
     ?
Catch Exception (generic)
 ?? Show: Generic error message
     ?
Finally (optional)
 ?? Cleanup resources
```

Large Plan (6 days/week, 20 exercises each)
